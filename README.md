# 🍎 iOS Font Pack for Android (Magisk Module)

Bring a clean, modern iOS typography experience to your rooted Android device.

This Magisk module replaces Android's default system fonts with **SF Pro Regular** for Latin-based languages (English, numbers, and most Western languages) and **Geeza Pro** for Arabic. The goal is to provide a font experience that closely resembles iOS while maintaining excellent readability and proper Arabic shaping across the system.

Unlike simply replacing a single font file, this module combines two fonts that complement each other perfectly:

* **SF Pro Regular** handles English and other Latin characters.
* **Geeza Pro** handles Arabic characters with proper glyphs and spacing.

The result is a much cleaner and more natural multilingual experience compared to using a single font for every language.

# 📖 Why This Module?

Most Android devices either use Roboto, Google Sans, Oppo Sans, MiSans, SamsungOne, or another OEM font depending on the manufacturer.

While these fonts are perfectly functional, many users prefer the appearance of Apple's typography. SF Pro has a modern, minimal, and highly readable design that looks excellent throughout the Android interface.

The challenge is that SF Pro does **not** include complete Arabic support.

That's where **Geeza Pro** comes in.

Geeza Pro is Apple's Arabic typeface used throughout iOS and macOS. It offers beautiful Arabic calligraphy, proper ligatures, balanced spacing, and excellent readability.

By combining both fonts, this module delivers an experience that closely matches Apple's multilingual font stack.

# ⚙ Installation

### Requirements

* Rooted Android device
* Latest Magisk installed

### Steps

1. Download the module ZIP.
2. Open the Magisk app.
3. Go to **Modules**.
4. Press **Install from Storage**.
5. Select the downloaded ZIP.
6. Wait for installation to finish.
7. Reboot your device.

That's it.

---

# 🔄 Uninstallation

If you ever want to restore your original fonts:

1. Open Magisk.
2. Disable or remove the module.
3. Reboot.

The original system fonts will be restored automatically since Magisk performs all modifications systemlessly.

# ❓FAQ

## Does this modify the system partition?

No.

Everything is applied through Magisk's systemless overlay.

---

## Will this survive OTA updates?

Usually yes, although you may need to reinstall or re-enable the module after certain updates.

---

## Can I uninstall it anytime?

Yes.

Simply remove the module from Magisk and reboot.

---

## Does this work without root?

No.

Magisk root is required.

---

## Does this include emoji replacements?

No.

This module only replaces system fonts.

---

## Why use Geeza Pro instead of SF Pro for Arabic?

SF Pro doesn't include a complete Arabic typeface. Apple uses Geeza Pro (or related Arabic fonts depending on the OS version) for Arabic text, making it the natural companion to SF Pro.
